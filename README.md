# BDE-Mechanical
Code for BDE Mechanical - Royal

*FLASHING INSTRUCTION*
CAN 0 on the SC units is 500kbit/s, while the default for SC units is 250. Code flashes can be done on a CAN that changes speed, but they will report a timeout and failure. The code likely will be written, but is recommended to re-flash the code again after the CAN baud is changed.
